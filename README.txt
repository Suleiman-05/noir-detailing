# NOIR DETAILING — сайт автодетейлинга

## Запуск
1. Распакуйте архив.
2. Откройте папку в VS Code.
3. Откройте `index.html` в браузере. Можно использовать расширение Live Server.

## Обязательно замените перед публикацией
Откройте `index.html` и найдите внизу `const CONFIG = { ... }`.
- `phoneDisplay` — номер, который будет виден на сайте.
- `phoneTel` — номер для звонка в формате +79990000000.
- `whatsapp` — номер WhatsApp в международном формате без `+`, пробелов и скобок.

Также замените:
- `Ваш город, адрес студии`
- часы работы
- цены и перечень услуг
- демонстрационные отзывы на настоящие отзывы с разрешения клиентов
- демонстрационные фото на реальные фотографии студии и выполненных работ

## Что работает
- адаптивная версия для телефона, планшета и компьютера;
- навигация и мобильное меню;
- каталог услуг с кнопками записи;
- калькулятор ориентировочной стоимости;
- FAQ с раскрывающимися ответами;
- форма заявки, которая формирует сообщение и открывает WhatsApp;
- кнопки связи и телефонные ссылки.

## Важно
Это готовый фронтенд-сайт без платных библиотек и без сервера. Форма передаёт заявку через WhatsApp, а не сохраняет её в базе данных и не отправляет в Telegram. Для автоматического приёма заявок без WhatsApp понадобится отдельный backend или подключённый сервис форм.
Изображения загружаются из Unsplash, шрифт — из Google Fonts, поэтому для их отображения нужен интернет. Для коммерческого использования проверьте лицензии и замените изображения на собственные или лицензированные.
